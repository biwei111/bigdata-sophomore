# bigdata-sophomore
大数据专业大二学生代码仓库，Java,C,Python,大数据，Web,小程序开发（可能还会有游戏开发）

## 📚 学习路线
1. 主线：Java 基础 → SpringBoot Web后端 → 大数据开发（Hadoop、Spark）
2. 副线：C语言数据结构、算法刷题、Python、机器学习、AI应用开发
3. 拓展：前端Web网站、微信小程序项目
4. 备选方向：数据安全基础
5. 备选方向：游戏开发

## 📁 文件夹目录规划
- /java-study        Java基础练习代码
- /c-datastructure   C语言、链表、栈、队列、树、数据结构代码
- /python-numpy      Python、Numpy、Pandas、机器学习练习
- /web-demo          Web网页前端练习（HTML/CSS/JS）
- /mini-program      微信小程序Demo
- /leetcode          LeetCode算法刷题代码
- /notes             学习笔记、Bug踩坑记录
- /games             游戏开发，Unity引擎学习
